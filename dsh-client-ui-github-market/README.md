# dsh-client-ui-github-market

Plugin marketplace tab in Settings: browse/search/install GitHub dsh-plugin topic plugins.

A DeepSeek Harness plugin (topic: `dsh-plugin`).

## Install

```sh
dsh plugin --profile <profile> add dsh-client-ui-github-market
```

Then restart DSH Desktop (or `dsh --profile <profile>`). See
[README.zh.md](README.zh.md) for details.
