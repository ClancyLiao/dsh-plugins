# dsh-client-ui-composer-optimize

A polish icon at the bottom-right of the composer input that optimizes the drafted prompt via the model.

A DeepSeek Harness plugin (topic: `dsh-plugin`).

## Install

```sh
dsh plugin --profile <profile> add dsh-client-ui-composer-optimize
```

Then restart DSH Desktop (or `dsh --profile <profile>`). See
[README.zh.md](README.zh.md) for details.
