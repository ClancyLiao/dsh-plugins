# dsh-github-market

Host half of the plugin marketplace: GitHub dsh-plugin topic sync, caching, and install endpoints.

A DeepSeek Harness plugin (topic: `dsh-plugin`).

## Install

```sh
dsh plugin --profile <profile> add dsh-github-market
```

Then restart DSH Desktop (or `dsh --profile <profile>`). See
[README.zh.md](README.zh.md) for details.
