# dsh-plugin-inventory-notes

Serves /plugin-notes.json with a one-line summary (Chinese from README.zh.md, English from package.json) for every loaded plugin.

A DeepSeek Harness plugin (topic: `dsh-plugin`).

## Install

```sh
dsh plugin --profile <profile> add dsh-plugin-inventory-notes
```

Then restart DSH Desktop (or `dsh --profile <profile>`). See
[README.zh.md](README.zh.md) for details.
