# dsh-plugin-composer-optimize

POST /composer/optimize: polish the composer draft with the configured DeepSeek model.

A DeepSeek Harness plugin (topic: `dsh-plugin`).

## Install

```sh
dsh plugin --profile <profile> add dsh-plugin-composer-optimize
```

Then restart DSH Desktop (or `dsh --profile <profile>`). See
[README.zh.md](README.zh.md) for details.
