# dsh-client-ui-plugin-notes

Replaces the plugin-list settings tab with a version that shows a one-line summary on every plugin card.

A DeepSeek Harness plugin (topic: `dsh-plugin`).

## Install

```sh
dsh plugin --profile <profile> add dsh-client-ui-plugin-notes
```

Then restart DSH Desktop (or `dsh --profile <profile>`). See
[README.zh.md](README.zh.md) for details.
