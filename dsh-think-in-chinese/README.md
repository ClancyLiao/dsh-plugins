# dsh-think-in-chinese

Make the model's thinking/reasoning output always use Simplified Chinese.

A DeepSeek Harness plugin (topic: `dsh-plugin`).

## Install

```sh
dsh plugin --profile <profile> add dsh-think-in-chinese
```

Then restart DSH Desktop (or `dsh --profile <profile>`). See
[README.zh.md](README.zh.md) for details.
