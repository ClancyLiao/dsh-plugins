# dsh-client-ui-account-usage

Account balance badge at the bottom of the sidebar with a detail popover.

A DeepSeek Harness plugin (topic: `dsh-plugin`).

## Install

```sh
dsh plugin --profile <profile> add dsh-client-ui-account-usage
```

Then restart DSH Desktop (or `dsh --profile <profile>`). See
[README.zh.md](README.zh.md) for details.
