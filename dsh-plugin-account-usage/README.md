# dsh-plugin-account-usage

GET /account/usage: DeepSeek account balance via /user/balance with a short cache.

A DeepSeek Harness plugin (topic: `dsh-plugin`).

## Install

```sh
dsh plugin --profile <profile> add dsh-plugin-account-usage
```

Then restart DSH Desktop (or `dsh --profile <profile>`). See
[README.zh.md](README.zh.md) for details.
